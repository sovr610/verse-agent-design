            Tubes and tokens

            Two tokens drive every color: --phos, the lit phosphor, and --tube, the unlit glass. The other shades are mixed from those two. Set data-phosphor on <html> to change the whole page, or on any element to give just that part its own tube.

            Shades of the current tube

            --phos-hiHeadings and the brightest marks
            --phosBody text and selected rows
            --phos-dimSecondary text, rules, idle controls
            --phos-lowDisabled text and meter tracks
            --phos-fillReadout cells and status bars
            --phos-washHover rows and focused inputs
            --tubeUnlit glass behind the content
            --hazardDamage, stolen goods, critical alerts

            Screen effects

            .pip-crt turns any box into a tube: curved-glass shading, vignette, scanlines and a slow refresh band. .pip-page lays scanlines over the whole page. .pip-scanlines is the mask technique from the Codemotion article: it darkens only lit pixels. Every effect stops under reduced motion and can be switched off with Pip.setFx().

            Buttons

            Buttons invert when hovered or focused. Put a <kbd> inside to show the keyboard shortcut. Use the danger style only for actions that lose something.

            Hold to confirm

            For actions that can't be undone, ask for a hold instead of a dialog. The fill grows while the button is held, and letting go early cancels. Listen for pip:confirm.

            Text fields

            Inputs read like a terminal prompt: VT323, an underline and a block caret. Wrap an input in .pip-prompt to add the leading mark. Mark errors with aria-invalid and say how to fix them.

            2 to 24 characters.

            Tabs and paging

            Main tabs sit on a rule that notches up around the active one. Sub tabs fade with distance from the active tab. Both use role="tablist" with data-pip-tabs, and the arrow keys move between tabs.

            Lists and readouts

            The core Pip-Boy layout: a list on the left, the selected item's numbers on the right. The selected row inverts. Add data-equipped to light the square in front of an item. Readout rows sit on filled cells with a thin seam between them.

            Tags and tooltips

            Tags mark an item's state. The screen is one color, so state shows as form: filled, outlined, or hazard red for things that hurt. Add data-pip-tip to any element without its own ::after for a short tooltip.

            Panels

            A panel puts its title into the top rule, and the side rules fade out downward like the HUD brackets. Add --closed for a full frame. Disclosures hold secondary detail, and an empty state says what will appear and how to get it.

            Dialogs and loaders

            Compass, map, scope

            The compass strip takes markers by bearing in data-markers; turn it with Pip.compass(el).set(degrees). The map draws seeded contour lines on a canvas under real buttons for each marker. The scope draws the radio waveform. All three redraw when the tube changes.

            Terminal

            A terminal is VT323 on a .pip-crt. Lines marked .pip-terminal__line type themselves out when you call Pip.type(el), or on load with data-pip-type; a click or key press skips to the end. Menu entries are buttons. Try typing help at the prompt.

            Password hacking

            Pick a word from the memory dump. A wrong guess tells you its likeness: how many letters sit in the same position as in the password. You get four attempts. The game builds itself inside any element with data-pip-hack, and fires pip:unlocked or pip:locked.
